- Visual inspection confirmed the next step precedes unavailable-service notices; the mobile action is above the fold, product identity remains visible, and resources are distinguishable.
- Activity document width equals viewport width at 1440, 768 and 390; no page-level horizontal overflow observed. Long setup commands keep their existing contained scrolling.
- Verified keyboard activation of the next-step link and technical-details expander. The navigation drawer dismisses with Escape and restores focus to its trigger.
- CSS-token contrast spot checks: body/background 17.69:1, muted text/background 6.27:1, muted text/muted notice 5.91:1, sidebar text 14.60:1, primary button text approximately 6.69:1, success badge 4.66:1, warning badge 4.70:1, danger badge 4.72:1. These are token calculations, not a complete accessibility certification. Existing reduced-motion support is retained. A screen-reader session was not performed.
- Regression checks cover actionable empty-state navigation and non-alert 501 status without Retry, alongside the existing session, approval, credential and review-confirmation tests. Shared contracts, backend code and dependencies are unchanged by the design pass.

## Verdict

The Lovable direction remains coherent: a quiet document workspace anchored by a dark sidebar and restrained accent. The most important improvement is making the human's next action clear before backend limitations. That change is now implemented, with unavailable capabilities still explained accurately.
